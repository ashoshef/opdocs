Review recent updates and improvements to Open Path Warehouse.

## Open Path 206

**Released:** April 2, 2026

### Updates

- **Improved HUD reporting performance.** We’ve streamlined how HUD APR and SPM reports are built, reducing duplication and improving performance for faster, more reliable results.

---

## Open Path 205

**Released:** March 26, 2026

### Updates

- **Exclude projects from CAS syncing using project groups.** You can now exclude specific projects from syncing to CAS by using project groups, providing more precise control over the data that is shared.
- **Supplemental Data tab visibility improvements.** The **Supplemental Data** tab is now hidden when the ROI has expired, reducing on-screen clutter.

---

## Open Path 204

**Released:** March 19, 2026

### Updates

- **Expanded HOPWA CAPER reporting tabs.** We’ve added the P-FBH and ST-TFBH tabs to the HOPWA CAPER report, providing more complete visibility into HOPWA data.

---

## Open Path 201

**Released:** February 26, 2026

### Updates

- **ROI expiration date visibility on the client dashboard.** The client dashboard now displays the ROI expiration date, making important timelines easier to track and manage.
