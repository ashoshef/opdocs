Use intake and exit assessments to manage the beginning and end of a client enrollment. Intake assessments collect required enrollment information, while exit assessments record the client's completion or departure from a project.

## Complete an Intake Assessment

An Intake Assessment becomes available when a client is enrolled in a project. Until the intake assessment is completed, the enrollment remains in an Incomplete status and additional assessments cannot be added.

> If the project has Auto Enter enabled, a blank intake assessment is automatically saved during enrollment. In this case, the client is considered fully enrolled even if the intake assessment has not been completed.

1. Open the project enrollment and select the client whose intake assessment you want to complete.
2. Open the intake assessment using one of the following options:
   - Click the document icon next to the entry date
   - Click **Finish Intake Assessment** in the Household Tasks card
   - Open it from the Assessments table
3. If you are on the Household page, click **Intake Assessment**.
4. If you are on the Assessments page, click **Finish Intake**.
5. Complete all required and applicable fields with the client.
6. Click **Save** to finish later or **Submit** to complete the assessment.
7. If the assessment is saved but not submitted, it will appear in the Assessments table with an alert icon indicating it is incomplete.
8. Reopen the assessment to continue editing. A banner will indicate that the assessment is still in progress.
9. When all information has been completed, click **Submit**.
10. If required fields are missing, review the warning message and confirm submission if appropriate.
11. After submission, the assessment will appear as completed in the Assessments table.

## Complete an Exit Assessment

> [[!WARNING]]
> Each enrollment can have only one Exit Assessment. Once submitted, the client is no longer considered actively enrolled in the project.

1. Open the client's enrollment record.
2. Open the exit assessment using one of the following options:
   - Click the document icon next to the exit date in the Enrollment Details card
   - Open the Assessments page
3. If you are on the Assessments page, click **New Assessment** and select **Exit Assessment**.
4. Complete all required and applicable fields, then click **Submit**.
5. After submission, the client will be exited from the enrollment.
