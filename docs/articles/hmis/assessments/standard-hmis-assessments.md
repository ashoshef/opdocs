HUD-required assessments collect standardized data at key points in a client's participation in a project. They are a core part of the enrollment record in HMIS and are used to track client information, household details, and eligibility over time. Most enrollments include multiple assessments completed at different stages of participation.

## How Assessments Work

Each assessment is completed at a specific stage of the client's enrollment. The number and type of assessments required depend on project setup and funder requirements. Assessment structure can vary based on funder requirements, project type, household composition, and program-specific data collection.

## Data Collection Stages

HUD-required assessments are organized by Data Collection Stage, which determines when the assessment is completed and what information is required:

- Project Start — Intake Assessment
- Project Update — Update Assessment
- Project Annual — Annual Assessment
- Project Exit — Exit Assessment
- Post Exit — Post-Exit Assessment

Each stage aligns with a specific point in the client's participation and ensures consistent data collection across projects.

## Assessment Configuration

Assessment forms may include additional questions beyond HUD requirements, depending on your project setup. These questions are used to collect program-specific information and may vary between projects. If you are a System Administrator and need to add or modify assessment questions, see [Use the Form Builder](../../administration/forms-assessments/form-builder.md).

## Accessing Assessments

1. Open the client's enrollment and navigate to the Assessments page.
2. Click **New Assessment** and select the assessment type you want to add.

### Intake Assessment

The Intake Assessment collects required information at project start, including client demographics, household details, and program eligibility. It must be completed for the client to be considered fully enrolled.

> [[!NOTE]]
> If the intake assessment is not completed, the enrollment remains in an Incomplete status and no additional assessments can be added. If the project has Auto-Enrollment configured, a blank intake assessment is automatically saved at enrollment and the client is considered enrolled.

For step-by-step instructions, see [Complete Intake and Exit Assessments](complete-intake-and-exit-assessments.md).

### Update Assessment

The Update Assessment records changes during a client's enrollment, such as updates to income, living situation, or household composition.

1. Select **Update Assessment** from the assessment type menu.
2. Complete all required and applicable fields, then click **Submit** or **Save** to finish later.

### Annual Assessment

The Annual Assessment is completed once per year to review and update a client's information while they remain enrolled.

1. Review the Household Tasks card if an annual assessment is due. A task appears when an annual assessment is due within 30 days.
2. Complete all required and applicable fields, then click **Submit** or **Save** to finish later.

### Exit Assessment

The Exit Assessment records a client's exit from a project, including destination and final program data.

> Each enrollment can have only one exit assessment. Once submitted, the client is no longer enrolled and no additional exit assessments can be created.

For step-by-step instructions, see [Complete Intake and Exit Assessments](complete-intake-and-exit-assessments.md).

### Post-Exit Assessment

The Post-Exit Assessment is used to collect follow-up information after a client exits a project, such as housing stability or outcomes.
