Upload, view, update, and delete files from a client's profile page.

1. Open the client's profile page.
2. Click **Files** in the left sidebar.
3. Review existing files. The table shows file tags, associated enrollments or projects, and upload dates.
4. Click **Upload** to add a new file.
5. In the upload window, select a file (up to 3 MB), add a file tag, and choose any visibility or confidentiality settings.
6. Select the file from your computer and click **Open**.
7. Select a file tag. If needed, choose **Other**.
8. Click **Upload File**.
9. Confirm the file appears at the top of the files list.
10. To view or manage a file, click the file row or use the action menu.
11. In the file window, you can download, edit, or delete the file.
12. To edit a file, click **Edit**, update the file tag, visibility, or confidentiality settings, then click **Save Changes**.
13. To delete a file, open the file, click **Delete**, and confirm the deletion.
14. Confirm the file is removed from the files list.
