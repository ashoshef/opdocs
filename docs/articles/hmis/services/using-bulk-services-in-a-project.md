Use Bulk Services to add, enroll, assign, or remove the same project service for multiple clients at once. This is helpful for programs that provide the same service to many participants and want to reduce duplicate data entry.

## Configure the Bulk Service

1. Select the project where you want to add bulk services.
2. Click **Bulk Services** in the sidebar.
3. Open the **Service Type** dropdown.
4. Select the service type you want to add in bulk. See [Add Services to an Enrollment](add-services-to-an-enrollment.md) for more on managing which services are available.
5. Review the Service Date. It defaults to today — use the date picker if the service was provided on a different date.

## Assign Services to Enrolled Clients

1. Click the **Search Clients** search bar to find a client.

> [[!NOTE]]
> Client search looks across all of HMIS, not just the selected project. A client does not need to already be enrolled in the project to appear in search results.

2. Click **Assign** for the client you want to add the service to.
3. To assign multiple clients at once, use the checkboxes on the left side of the table. The top checkbox selects all clients on the current page.
4. Review the selected client count in the table header, then click **Assign** to assign the service in bulk.

## Enroll and Assign Existing HMIS Clients

1. If a client exists in HMIS but is not enrolled in the project, click **Enroll + Assign**.
2. After using Enroll + Assign, confirm the client's entry date matches the selected service date.

## Add and Assign a New Client

1. If the client is not already in HMIS, click **Add New Client**.
2. Choose whether to add an individual client or a household.
3. To add one client, select **Add New Client**. Enter the client information you have — only a first or last name is required, and you can edit the profile later. Click **Create and Enroll Client**.
4. The new client will appear in the assigned services table. Click **Assign** to assign the service.

## Add and Assign a New Household

1. To add a household, open the **Add New Client** dropdown and select **Add New Household**.
2. Complete the household enrollment on the new page.
3. Enroll the household. See [Add an Enrollment](../enrollments/add-an-enrollment.md) if you need help.
4. When the household is complete, click **Back to Bulk Services**.
5. The household will appear in the assigned services table. Assign the service for the selected date as needed.

## Remove Bulk Services

1. To remove a service from one client, click **Unassign** for that client. The button changes back to Assign.
2. To remove the service from multiple clients, use the checkboxes to select the assigned clients you want to remove.
3. Click **Remove**.
4. Confirm the clients have been unassigned from the service.
