Update enrollment details for a client after they have been enrolled in a project.

1. Go to **Projects** and select the project that contains the enrollment you want to edit.
2. Select the enrollment you want to update. Alternatively, open the client's profile and go to the Enrollments tab to access the same enrollment.
3. On the enrollment overview page, review and update details such as entry date, exit date, and other enrollment information.
4. To edit entry or exit dates, click the document icon next to the date or status.
5. To edit other fields, click the pencil icon on the right side of the row.
