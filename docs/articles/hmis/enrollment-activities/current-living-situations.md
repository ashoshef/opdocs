Current Living Situations (CLS) track where a client is staying during an enrollment. CLS records are required for certain funders and project types as defined by the HUD HMIS Data Standards.

## Access Current Living Situations

1. Select **Current Living Situations** from the enrollment sidebar.

## Add a Current Living Situation

1. Click **+ Add Current Living Situation**.
2. Select the date the information was collected.
3. Select the current living situation from the dropdown.
4. Enter any additional location details. This field is optional but can help other users understand the client's situation.
5. Click **Save**.

## Edit a Current Living Situation

1. Click the action menu for the record you want to update.
2. Select **Edit** in the record view.
3. Make your changes and click **Save**.

## Delete a Current Living Situation

1. Click the action menu for the record you want to remove.
2. Click **Delete**.
3. Confirm the deletion.
4. After deletion, you'll return to the Current Living Situations page.
