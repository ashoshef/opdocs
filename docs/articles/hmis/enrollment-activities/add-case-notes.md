Add, edit, and delete case notes within a client's enrollment to document interactions, updates, and services provided.

## Access Case Notes

1. Open the enrollment for the client.
2. Click **Case Notes** in the sidebar.

## Add a Case Note

1. Click **Add Case Note**.
2. Select the Information Date for the case note.
3. Select the Method of Contact.
4. Enter your notes in the Note field.
5. Click **Save**.
6. Confirm the case note appears in the table.

## Edit a Case Note

1. In the table view, select the case note you want to edit.
2. Make your changes and click **Save**.

## Delete a Case Note

1. In the table view, select the case note you want to delete.
2. Click **Delete**.
3. Click **Yes, Delete Case Note** to confirm.
4. Confirm the case note is removed from the table.
