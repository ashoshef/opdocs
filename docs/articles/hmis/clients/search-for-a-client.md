Use the **Clients** tab to find a client quickly, whether you need a broad search using partial information or a more precise search with multiple details.

Open the client search from the **Clients** tab in the top menu. There are two ways to search for a client: Broad Search and Specific Search.

## Broad Search

Broad Search is displayed by default. You can search by first name, last name, date of birth (MM/DD/YYYY), Social Security number (XXX-XX-XXXX), or Personal ID. Partial first or last names are supported, but you must enter at least 3 characters.

Broad Search works best when you enter at least a few characters. If the results are too broad, add more information to narrow them down.

## Specific Search

Use Specific Search when you need to narrow results more precisely, especially when multiple clients have similar names. With Specific Search, you can search using first name, last name, Personal ID, Social Security number, and date of birth at the same time.

Use Specific Search when a Broad Search returns too many results or when you want to confirm you have the correct client.
