Create a new client record in HMIS after confirming the client does not already exist.

1. Click **Clients** in the top navigation to open the client search page.
2. Use the Search tab to look for the client and confirm they do not already exist.
3. Click **Add New Client** in the top right.
4. Enter the client's name in the Client Name section. A first or last name is required.
5. Select the appropriate value from the **Name Data Quality** dropdown.
6. Click **Add Another Name** to include nicknames or alternate names.
7. Enter details in the Identification section, including date of birth and Social Security number, and select the appropriate data quality.
8. Complete the Demographics section as needed. This information is optional but recommended when available.
9. Add contact details in the Contact Information section using the available buttons to add addresses, phone numbers, or email addresses.
10. Upload a client image in the Client Image section if needed. This can also be added later.
11. Click **Create Client** to save the record.
12. Review the newly created client profile.
