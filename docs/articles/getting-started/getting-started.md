Open Path is made up of two main areas: **HMIS**, where staff manage clients, enrollments, and day-to-day case work, and **Warehouse**, where administrators manage reporting and system-wide data. This help center covers both, along with the admin settings that control access and configuration across the system.

## Where to go next

- **[Organizations & Projects](../organizations-projects/create-and-manage-organizations.md)** — set up the organizations and projects that structure your HMIS workspace.
- **[Admin & Configuration](../administration/users-access/manage-user-accounts.md)** — manage user accounts, roles, permissions, and custom forms.
- **[HMIS](../hmis/clients/search-for-a-client.md)** — day-to-day workflows for clients, households, enrollments, and assessments.
- **[Product News and Updates](../../../news/release-notes.md)** — what's changed in the most recent releases.
