Project groups organize related projects for reporting and analysis. They make it easier to run reports and review results across multiple projects.

> [[!NOTE]]
> Users need the **Can edit project groups** or **Can edit assigned project groups** permission to create and edit project groups. Access to a project group does not automatically grant access to each project in the group — users still need the appropriate project access.

## Open Project Groups

1. Open **HMIS Admin** in the right sidebar.
2. Under **Data**, click **Project Groups**.

## Create a Project Group

1. Click **Add Project Group**.
2. Complete the project group information:
   - **Name** — Enter a clear name for the project group. Include details that help distinguish it from other groups, such as the year, CoC, organization, or reporting purpose.
   - **Projects, Organizations, Project Types, and Data Sources** — Select the projects to include. These selections are additive: for example, selecting one project and one project type includes that project *and* every project in that project type.
   - **Access** — Select the users who should have access to the project group.
3. Click **Create Project Group**.

## Edit a Project Group

1. Select the project group you want to view or edit from the table.
2. On the project group review page, click **Edit** next to the project group name.
3. Update the project group details, project selections, or access settings as needed.
4. Click **Save Project Group**.

## Delete a Project Group

> [[!NOTE]]
> [[!WARNING]]
> Deleting a project group may affect reporting access or workflows that rely on that group. Confirm the group is no longer needed before deleting it.

1. Open the project group you want to delete, then click **Edit** next to the project group name.
2. At the bottom of the form, click **Delete Group**.
3. Confirm the deletion in the browser confirmation window.

## Project Group Notes

**Project Groups** are used to group projects for reporting, such as the Project Data Quality report.

**Access Groups** are used to assign access to a set of data. Project groups may be included in access groups, but they are not the same thing.

If a project doesn't appear in the project selection list, confirm that it has at least one enrollment — projects become available for project groups only after enrollments have been added.
