Configure project-level settings that control how enrollments behave for a project, organization, or project type.

1. Click **Admin** in the top navigation.
2. Click **Projects** in the sidebar.
3. Click **New Project Configuration**.
4. Select a configuration type:
   - **Auto Exit** — automatically exits clients after a set period of inactivity.
   - **Auto Enter** — creates an enrollment automatically when a service is added. Recommended for locally funded projects without required intake fields.
   - **Staff Assignment** — assign staff to enrollments for visibility and tracking.
   - **Coordinated Entry Referrals**
   - **Outgoing Referrals**
5. Choose whether the configuration applies to an organization, project, or project type.
6. Click **Save Changes**.
