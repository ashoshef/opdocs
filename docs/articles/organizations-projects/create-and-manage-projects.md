Projects live inside an organization and are where enrollments, assessments, and services are managed. If you haven't created an organization yet, see [Create an Organization](create-and-manage-organizations.md) first.

> [[!NOTE]]
> Creating a project requires admin access, even though projects are accessed from the **Projects** page.

## Create a Project

1. Go to **Projects**, then click **View Organizations**.
2. Select the organization where you want to create the project.
3. Click **+ Add Project**.
4. Enter the required details, then click **Create Project**.
5. Confirm the project appears in the organization's project list.

## Delete a Project

> [[!NOTE]]
> [[!WARNING]]
> Deleting a project may remove access to project setup and related project records. Only delete a project if you're sure it's no longer needed.

1. Go to **Projects** and select the project.
2. Open the project menu, then click **Overview**.
3. Click **Edit Project Details**.
4. Click **Delete Project**, then click **Yes, Delete Project** to confirm.
5. After deletion, you'll return to the organization page.

For project-level settings like Auto Exit, Auto Enter, and Staff Assignment, see [Configure Project Settings](configure-project-settings.md).
