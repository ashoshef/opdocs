Create user accounts by sending invitations and manage access from the User Accounts page.

1. Click **Warehouse Admin** in the sidebar.
2. Click **Users** in the Access section.
3. Click **Add a User Account**.
4. Complete the invitation form to create the user account and send an invitation.
5. Click **Send an Invitation**.
6. Click **Manage User Accounts** to return to the user list.
7. To manage a user, open the **Actions** dropdown for that user.
8. Select the action you want to take. Available actions include:
   - Resend invitation
   - Edit account information
   - Force a password reset
   - Deactivate the user account

Once an account exists, add the user to a [user group](manage-user-groups.md) to give them access.
