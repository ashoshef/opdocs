Create and manage user groups to organize users who need similar access. User groups work together with roles, collections, and access controls to determine what users can see and do in HMIS.

User groups are collections of users with similar characteristics or access needs. They help administrators manage permissions efficiently by allowing the same access setup to be applied to multiple users at once.

Access is controlled by combining three pieces: User Group, Role, and Collection. The user group defines who the access applies to, the role defines what actions they can perform, and the collection defines what data they can access.

## Access User Groups

1. Open the **HMIS Admin** menu in the right navigation.
2. Select **User Groups**.

## Create a User Group

1. Click **Add a User Group**.
2. Enter a descriptive name for the user group.
3. Add existing users using the **Users** field.
4. Click **Create User Group**.

## Add Users to an Existing User Group

1. Select the user group you want to update.
2. Add users using the **Users** field, then click **Update User Group**.

## Delete a User Group

> [[!NOTE]]
> User groups can only be deleted after all users have been removed from the group.

1. Open the user group and remove each user by clicking the **X** next to their name.
2. Click **Update User Group** to save your changes.
3. Return to the User Groups list and click **Delete Group**.
4. Confirm the deletion.

Next, see [Manage Roles and Permissions](manage-roles-and-permissions.md) to define what this group can do, or [Manage Access Controls](manage-access-controls.md) to put the whole access setup together.
